1. Platform Overview

Sarayu (formerly SaatSaheli) is a full-stack creative publishing and community platform that enables users to create, publish, and share digital books, articles, and image galleries. The platform features AI-powered content generation with multilingual (Hindi/English) support.

1.1 Key Features

  • Book Publishing: Create, edit, and publish digital books with drag-and-drop page editing
  • AI Cover Generation: Generate book covers using Stable Diffusion XL with 12+ artistic styles
  • Multilingual AI Prompts: Hindi-to-English translation for AI image prompts (Helsinki-NLP)
  • Document Upload: Import PDF and Word documents, auto-converted to page-based books
  • Flipbook Reader: Interactive page-flip style book reading experience
  • Galleries & Articles: Create and manage image galleries and articles
  • Community Chat: Real-time chat rooms across 6 categories
  • Social Features: Likes, comments, favorites, following/followers
  • Subscription Plans: Free, Premium, Gold, and Creator tiers via Stripe
  • Admin Dashboard: User management, content moderation, platform statistics

4.4 Password Reset Flow

User-Initiated Reset

  1. User calls POST /api/auth/forgot-password with email
  2. System generates a temporary password (logged server-side)
  3. User receives temp password and calls POST /api/auth/reset-password with old + new password

Admin-Initiated Reset (Super Admin Only)

  1. Super Admin calls PUT /api/auth/admin-reset-password/{userId}
  2. Password is force-reset without requiring old password verification

6.4 Content Moderation

  • Archive: Hides book from public view, can be recovered
  • Delete: Soft-deletes the book (status = DELETED)
  • Recover: Restores a deleted/archived book to DRAFT status
  • Chat moderation: Admin can delete any chat message (soft delete — shows as "[deleted]")

7. Super Admin Support — Elevated Operations

SUPER_ADMIN operations are irreversible in some cases. Exercise extreme caution with purge operations.

7.1 Super Admin Exclusive Capabilities

OperationEndpointMethodRisk Level
Change user role/api/admin/users/{userId}/rolePUTMedium
Force password reset/api/auth/admin-reset-password/{userId}PUTMedium
Purge single book permanently/api/admin/books/{bookId}/purgeDELETEHIGH
Purge all deleted books/api/admin/books/purgeDELETECRITICAL

7.2 Role Hierarchy

SUPER_ADMIN  (highest - can do everything)
    |
  ADMIN      (can manage users and content, cannot assign roles)
    |
   USER      (standard user - create and manage own content)

7.3 Role Assignment Rules

  • Only SUPER_ADMIN can assign or change user roles
  • Valid roles: USER, ADMIN, SUPER_ADMIN
  • ADMIN cannot promote other users to ADMIN or SUPER_ADMIN

Assigning a Role

PUT /api/admin/users/{userId}/role
Header: Authorization: Bearer {superadmin_jwt_token}
Body: { "role": "ADMIN" }

7.4 Purge Operations

Purge = Permanent Deletion. Data cannot be recovered after purge. Always verify before executing.
  • Single purge: Permanently deletes one book and all its pages
  • Bulk purge: Permanently deletes ALL books with status DELETED

18.4 Google Cloud Console — OAuth 2.0 Client ID Updates

Critical: Google OAuth login will break if these steps are not completed after the Render URL change.
  1. Go to Google Cloud Console
  2. Select the project (e.g., chproject-487021)
  3. Navigate to APIs & Services → Credentials
  4. Click on the OAuth 2.0 Client ID used by the app
  5. Under Authorized JavaScript origins, update:
    • Remove: https://saatsaheli.onrender.com
    • Add: https://sarayu.onrender.com
    • Keep: http://localhost:3000 (for local development)
  6. Under Authorized redirect URIs, update:
    • Remove: https://saatsaheli.onrender.com
    • Add: https://sarayu.onrender.com
    • Remove: https://saatsaheli.onrender.com/Login
    • Add: https://sarayu.onrender.com/Login
    • Keep: http://localhost:3000 and http://localhost:3000/Login
  7. Click Save
  8. Changes may take up to 5 minutes to propagate

18.5 OAuth Consent Screen Updates

  4. Update Authorized domains: add sarayu.onrender.com, remove old domain
  5. Update Privacy policy link to https://sarayu.onrender.com/policies

18.6 Stripe Dashboard Updates
